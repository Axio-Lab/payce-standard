# Payce standard

Open-standard infrastructure for Payce USSD payments on Solana (Rust / Actix).

This repository is the Payce USSD callback server: PAJ ramp integration, Solana transfers, merchant flows, and related services.

The codebase was developed in a local workspace (early folders included a small **test** layout and an **actix**-named directory) and was **renamed to Payce Standard** before publishing to GitHub as `Axio-Lab/payce-standard`.
